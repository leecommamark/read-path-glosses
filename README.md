# Read Path's gloss table -- retired

This repository published `glosses.tsv`, the merged English gloss table behind
the first version of Read Path (`read-path-app`). That version is retired, and
the table is no longer published.

The new Read Path is at <https://leecommamark.github.io/readpath/>. Its
dictionaries, readings and word lists ship with the app as data files, offered
under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Every
source is credited on the app's **About and licences** page.
